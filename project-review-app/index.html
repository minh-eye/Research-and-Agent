직접 진행한 프로젝트 자료(코드 설명, 기획서, 보고서, 슬라이드 등)를 업로드하면, 강점과 성장 지점을 진단하고 하네스/엔지니어링 관점의 보완점을 제안한 뒤 실재하는 GitHub 학습 경로로 이어줍니다. 점수는 매기지 않습니다.

무채점 · 코칭 우선 근거 기반 · 제출물 인용 실재성 · 웹 검색 검증 브라우저 내 추출
이 피드백은 이렇게 활용하세요

어떤 프로젝트를 진행하든, 이 피드백으로 다음 버전을 더 잘 설계할 수 있도록 도와드립니다.

  1. 01
    강점

    잘 설계된 지점을 자료 근거와 함께 짚어줍니다. → 유지하고 더 밀어붙일 부분

  2. 02
    성장 지점

    약점을 “무엇을 · 어떻게 · 왜”로 풀어줍니다. → 바로 고쳐서 다시 만들어 볼 부분

  3. 03
    엔지니어링 보완

    컨텍스트 · 에러처리 · 문서화 · 재현성 등 보강점. → 다음 버전 설계에 반영

  4. 04
    GitHub 학습 경로

    실재하는 레포 추천 + 다음 한 걸음. → 클론해 써보거나 구조를 뜯어보며 학습

고급 설정 (모델 · 엔드포인트 · 키 저장)

파일은 서버로 전송되지 않고 브라우저 안에서만 텍스트로 변환됩니다. 분석을 위해 추출된 텍스트만 Anthropic API로 전송됩니다. 정적 배포 시 도메인 허용·키 관리를 확인하세요.
