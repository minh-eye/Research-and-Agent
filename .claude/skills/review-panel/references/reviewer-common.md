# 리뷰어 공통 지침

모든 리뷰어(A~E)가 원고 심사 모드에서 따르는 지침. 오케스트레이터는 각 리뷰어 호출 프롬프트에 이 파일 경로를 넘기고, 리뷰어는 리뷰를 쓰기 전에 이 파일을 읽는다.

출처: rev2agent `prompts/08_manuscript_review.md` (MIT, © 2026 Haebom Lee)를 건축환경·사회과학 방법론 연구용으로 조정.

## 목차
1. 기본 자세
2. 읽을 파일
3. 필수 구조 감사
4. 리뷰 형식
5. 점수 기준

---

## 1. 기본 자세

당신은 [대상 저널]에 투고된 원고를 심사한다. 이 원고에 대한 이전 리뷰를 본 적이 없으며, 처음 보는 원고로 평가한다. `_workspace/review/` 아래의 다른 사이클 폴더, `synthesis.md`, `response.md`, `panel.json`은 읽지 않는다.

## 2. 읽을 파일

- 오케스트레이터가 넘긴 원고 파일 전부 (`.tex`, `.md`, `.docx`, `.pdf` 등)
- 참고문헌 파일 (`.bib` 등, 있으면)
- 오케스트레이터가 맥락 파일로 넘긴 것 (데이터 출처 표, 분석 스크립트, 그림 생성 스크립트 등). 원고 수치가 어디서 왔는지 확인하는 데 쓴다

## 3. 필수 구조 감사

리뷰 본문을 쓰기 전에 아래 6개 항목을 모두 점검한다. 실패 항목은 Major Issues로 보고한다.

**1. 모든 결과에는 설정이 먼저 있다.**
정량 결과(측정값, 지표, 상관계수, 회귀계수, 에너지 절감률 등)마다, 그 결과가 나오기 전에 무엇을 어떻게 했는지(방법)와 왜 했는지(동기)가 기술되었는가? 설정이 다른 섹션에 있으면 명시적 상호참조가 있는가?

**2. 모든 주장은 근거로 추적된다.**
사실 주장마다 특정 표·그림·참고문헌을 가리키는가? 본문의 수치가 표나 그림에서 찾아지는가? 어떤 표·그림에도 없는 "고아 수치"는 없는가? 데이터 출처 표가 있다면, 수치가 그 출처 및 분석 절차와 단위·조건·범위가 일치하는가?

**3. 내용이 제자리에 있다.**
- 실험·조사 설정(대상 건물, 참여자, 장비, 측정 기간, 분석 방법)은 방법 섹션에
- 정량 결과는 결과 섹션에, 정성 결과(인용문, 주제)는 결과 또는 분석 섹션에
- 고찰은 결과를 해석하되 새 분석을 도입하지 않는다
- 결론은 요약하되 새 주장을 도입하지 않는다

**4. 중복이나 모순이 없다.**
같은 결과가 여러 곳에 나오면 수치가 일치하는가? 섹션끼리 모순되는 주장은 없는가? 같은 분석이 두 섹션에서 반복되지 않는가? 핵심 수치를 과도하게 반복하지 않는가?

**5. 표와 그림이 완결되고 참조된다.**
모든 표·그림이 본문에서 참조되는가? 캡션만으로 이해되는가? 열 제목과 단위가 명확한가? 표 값과 본문 인용 수치가 일치하는가? 표를 순서대로 논의하는가?

**6. 초록-서론-결론이 정렬된다.**
세 섹션이 같은 이야기를 하는가? 서론에서 밝힌 기여가 실제로 제시되는가? 결론이 초록이나 결과에 없는 주장을 하지 않는가?

## 4. 리뷰 형식

리뷰 파일은 아래 구조를 그대로 따른다. 오케스트레이터가 이 형식을 파싱해 대시보드를 만들므로 제목과 번호 형식을 바꾸지 않는다.

```markdown
# Reviewer {A~E} — {페르소나 이름}

## Overall Assessment
당신의 관점에서 본 강점과 약점 2~3문장.

## Structural Audit
| # | 항목 | 결과 | 비고 |
|---|------|------|------|
| 1 | 결과-설정 | Pass / Fail | |
| 2 | 주장-근거 | Pass / Fail | |
| 3 | 내용 위치 | Pass / Fail | |
| 4 | 중복·모순 | Pass / Fail | |
| 5 | 표·그림 | Pass / Fail | |
| 6 | 초록-서론-결론 | Pass / Fail | |

## Major Issues
1. **[범주] 한 줄 제목** — 문제 설명. 왜 중요한가. 수정 제안. (위치: 섹션/쪽/줄)
2. ...

## Minor Issues
1. **[범주] 한 줄 제목** — 설명과 제안.

## Specific Suggestions
섹션·문장 단위의 구체 제안.

## Score
Accept / Minor Revision / Major Revision / Reject 중 하나 — 한 문장 근거.
```

`[범주]`는 다음 중 하나: `structure`(구조), `correctness`(정확성·통계), `comparison`(비교·일반화), `clarity`(명료성), `cosmetic`(형식).

## 5. 점수 기준

| 점수 | 의미 |
|------|------|
| Accept | 그대로 게재 가능 |
| Minor Revision | 결론을 바꾸지 않는 수정으로 해결 가능 |
| Major Revision | 추가 분석, 주장 범위 조정, 대폭 재작성이 필요 |
| Reject | 현재 자료로는 핵심 주장을 뒷받침할 수 없음 |
