새 원고 심사

원고를 올리고 목표 학술지를 고르면 다섯 명의 AI 심사위원이 서로의 의견을 보지 않고 각자 심사합니다. 이어서 편집위원장이 종합 보고서와 답변서 초안을 만듭니다. 사용량은 아래에 입력한 Anthropic API 키로 과금됩니다.

0 · Claude API 연결
키는 이 브라우저에서 api.anthropic.com으로만 전송됩니다. 키 발급
1 · 원고
원고 파일을 끌어다 놓거나 눌러서 선택 .docx · .pdf · .md · .txt
파일 대신 본문 붙여넣기
2 · 심사 조건
도메인 심사위원(C)이 이 분야 기준으로 봅니다.
이전 심사를 고르면 편집위원장이 이전 지적의 해소 여부를 대조합니다. 심사위원은 이전 리뷰를 보지 않습니다.
원고를 먼저 올려 주세요.

심사 기록

판정과 지적은 AI 심사위원의 의견이며 실제 학술지 심사 결과가 아닙니다. 원고 본문은 Anthropic API 심사 요청에만 쓰이고 기록에는 저장되지 않습니다. 기록은 이 브라우저(IndexedDB)에만 남습니다.
